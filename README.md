# 로또 6/45 분석기 v1

브라우저에서 바로 실행되는 정적 웹앱입니다.

## 실행
`index.html`을 브라우저로 열면 됩니다.

## 기능
- 회차/날짜/당첨번호/보너스 입력
- 최근 1년, 6개월, 3개월 및 최근 10/20/30회 분석
- 1~45 출현 횟수
- 출현 빈도 기준 1~10등급
- 제외 번호 지정
- 통계 가중 랜덤 추천 조합
- 추천 조합과 실제 당첨번호 대조

## 입력 형식
한 줄에:
`회차,YYYY-MM-DD,번호1,번호2,번호3,번호4,번호5,번호6,보너스`

주의: 샘플 데이터는 기능 시험용 예시이며 실제 당첨 데이터가 아닙니다.
로또 추첨은 독립 시행이며 과거 통계는 당첨을 보장하지 않습니다.
